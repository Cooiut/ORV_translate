# ORV 分层词汇加载与预检 Skill

## 触发时机
当用户指示翻译某一章节（如 `ch_1047.xhtml`）或提供源文件时，**在正式翻译文本之前**执行本 Skill 流程。

---

## 核心执行流程（三阶段流水线）

```
[Phase 1: 预检与加载] ──> [Phase 2: 翻译与原地写入] ──> [Phase 3: 词库与快照更新]
 ├─ 加载 core.md           ├─ 严格遵守文体/标点规范     ├─ 写入未收录新词条
 ├─ 双向正则/差集扫描       └─ 保留标签/原地替换        ├─ 更新 memory_checkpoint
 ├─ 按需 view_file 分类表                              └─ 简短汇报完成
 └─ 输出清单与高危提示卡
```

---

## Phase 1: 扫描、匹配与词汇加载

### 第一步：加载核心词汇（必须全量加载）
使用 `view_file` 读取 `.agents/glossary/core.md`，将其**全部内容完整纳入**本次翻译的核心上下文。  
`core.md` 中的所有词条（含"后期战场高频词"）无论章节内容如何，均作为常驻基底。

### 第二步：双向精准扫描与特征提取

结合 Agent 的文本解析与工具能力，执行**正向提取**与**反向比对**：

1. **正向特征提取**（从源 XHTML 文件中提取候选专有名词）：
   - **大写名词短语**：连续大写开头的词组（如 `Supreme God of Light`, `Master of the Erased Void`）。
   - **符号包裹词**：单引号 `'...'`、双引号 `"..."`、方括号 `[...]` 内的术语（如 `'Einherjar'`, `'King's Road'`）。
   - **韩文罗马音特征词**：含 `oo`, `ae`, `eo`, `hyuk`, `yeon`, `woo`, `eun`, `jin`, `hyun` 等人名/地名特征。
   - **系统级标记**：如 `Main Scenario`, `Sub Scenario`, `Hidden Scenario`, `Reward:`, `Penalty:` 等。

2. **反向词库检索**：
   - 检查已收录词汇表键名（`->` 左侧）是否在源文中出现（忽略大小写）。

### 第三步：规范化匹配与差集比对（五步法）

对提取出的候选词与词汇表键名执行规范化比对：

```
A. 规范化清洗：
   - 统一转为小写对比
   - 去除所有格（'s → 空字符）
   - 连字符与空格等价化（super-giant = super giant）
   - 去除首尾包裹引号/括号

B. 双向子串与别名展开：
   - 词汇表 "/" 分隔的多个别名各自作为独立键名匹配（如 Dream Eater / Devourer of Dreams）。
   - 包含匹配（源文 "Fear Realm" ⊂ 词汇表 "Fear Realm Expedition" -> 命中）。

C. 差集比对（新词发现）：
   - 若提取出的专有名词在 core.md 及 8 大分类表中均未命中，不得静默跳过；
   - 将其列入 ⚠ 未收录词，并结合 ORV 设定给出【建议译名】和【建议所属分类】。

D. 通用常识过滤：
   - 仅对通用世界神话（如 Zeus、Thor 等）、通用地名可直接采用公认标准译名，其余 ORV 专有名词一律严格比对。
```

### 第四步：按需完整加载分类词汇表
若第二/三步中命中了某个分类中的词条，调用 `view_file` **完整读取**对应的分类文件，确保同场景关联词汇（如同一阵营神名、成套技能）全部激活：

| 分类文件 | 涵盖内容 | 适用场景 |
|---|---|---|
| `.agents/glossary/characters.md` | 角色 / 身份 / 阵营 | 章节含角色互动、阵营对抗 |
| `.agents/glossary/modifiers.md` | 星座名号 / 故事印记 | 章节含星座名号展示、故事播报 |
| `.agents/glossary/skills_attrs.md` | 技能 / 属性 / 星痕 | 章节含战斗、技能发动、属性面板 |
| `.agents/glossary/items.md` | 装备 / 道具 / 星遗物 | 章节含道具使用、星遗物展示 |
| `.agents/glossary/locations.md` | 地点 / 场景区域 | 章节含场景切换、地理描写 |
| `.agents/glossary/scenarios.md` | 任务 / 系统分类 | 章节含系统任务、难度结算 |
| `.agents/glossary/monsters.md` | 怪物 / 灾难 / 世界观符号 | 章节含灾难、外神、异兽战斗 |
| `.agents/glossary/misc.md` | 历史线 / 概念 / 杂项 | 章节含历史政权、元叙事术语 |

### 第五步：输出词汇清单与高危规则提示卡

在进入正式翻译前，输出以下结构化预检报告：

```markdown
【本章词汇清单】
（来源：core.md 全量 + 本章分类匹配命中）

★ 核心词汇（core.md 常驻已加载）

★ 本章命中：
  [角色] Surya -> 苏利亚
  [名号] Supreme God of Light -> 最高之光神
  [技能] Armed Fortress -> 武装堡垒
  ...

⚠ 未收录新词（请确认建议译名）：
  [建议归入 characters.md] Final Chief Engineer -> 建议译为「最终列车长」
  [建议归入 scenarios.md] 'Hole' -> 建议译为「深坑」

──────────────────────────────────────────────────────
⚠ 高危规则提示卡（翻译执行前强制激活）

1. 括号体系严格区分（最高频失误点）：
   ❌ 【苏利亚：你小子……】  （错误！星座普通当面对话严禁使用黑双括号）
   ✅ ［苏利亚：你小子……］  （正确！星座/鬼怪/化身同场景当面对话一律使用全宽方括号）
   ✅ 「内心独白 / 专属心声」 （使用直角单引号）
   ✅ 【跨维度真言 / 跨空广播】（仅在真言大喊时使用）
   ✅ ［系统提示 / 技能名称 / 任务结算］（使用全宽方括号）

2. 专有名词必须严格对标（严禁随意自译）：
   ❌ 副任务 / 次要任务  →  ✅ 支线任务（Sub Scenario）
   ❌ 主要任务          →  ✅ 主线任务（Main Scenario）
   ❌ 秘密任务          →  ✅ 隐藏任务（Hidden Scenario）
   ❌ 概率 / 概率风暴    →  ✅ 概然性 / 概然性风暴（Probability）

3. 标点与格式规范：
   - 清除对话句首的前导破折号（`"——` → `"`），保留句尾拉长音（`"我——"`）。
   - 英文省略号 `...` 统一转为中文全角 `……`。
   - 英文感叹号转为全角（`！！`、`！？`），避免半角感叹号混排。
──────────────────────────────────────────────────────
```

## Phase 2: 翻译执行与原地替换

1. **读取源文件与对照翻译**：从 `orv_sequel_eng/OEBPS/` 读取英文源文件，严格遵守 `AGENTS.md` 格式规范与文体润色指南。
2. **排版连贯性**：
   - 遵循中文阅读连贯性，对英文源文件中冗余的连续 `<br/>` 进行合理缩减（多个连续 `<br/>` 仅删除一个），但严禁破坏段落 `<p>` 标签与文件 HTML/XHTML 闭合结构。
3. **原地替换写入**：将翻译完成的高质量中文直接写入目标文件 `orv_sequel/OEBPS/ch_xxx.xhtml`。

---

## Phase 3: 词汇持久化与快照更新

完成文件修改后，执行收尾闭环：
1. **追加新词条**：将本章确认的新专有名词追加到对应 `.agents/glossary/xxx.md` 末尾（若连续3章高频出现，则晋升至 `core.md`）。
2. **更新记忆快照**：在 `.agents/memory_checkpoint.md` 中追加当前章节剧情简述与进度编号。
3. **结算回复**：仅简要汇报“完成”及词汇表变更、Checkpoint 更新摘要。
